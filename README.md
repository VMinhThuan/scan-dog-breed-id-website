# DogBreedID - Scan Dog Breed ID Website

An AI-powered Fine-Grained Dog Breed Classification Web Application built with ReactJS, Vite, Tailwind CSS, Lucide Icons, Framer Motion, and i18next (Bilingual Support: Vietnamese & English).

## Key Features

- **Fine-Grained Classification Visual Workspace**: Interactive photo upload & preview for dog breed recognition.
- **Top-5 Class Probabilities & Grad-CAM Interpretability**: Visual heatmaps & probability distribution across 120 Stanford Dogs classes.
- **Complete Bilingual i18n Support**: Full internationalization for Vietnamese (`vi`) and English (`en`) with persistent language selection (`localStorage`) and document title updates.
- **Responsive & Modern Design**: Scientific minimalism × AI × Pet aesthetic responsive across mobile, tablet, and desktop screens.
- **Academic Thesis Context**: Built for graduation defense demonstration featuring CNN backbones comparison (ResNet50, EfficientNet-B0, MobileNetV3).

## Tech Stack

- **Frontend**: ReactJS, Vite, Tailwind CSS, Framer Motion, Lucide React
- **Internationalization**: `i18next`, `react-i18next`
- **Build & Deploy**: Vite, Vercel

## Local Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
